# Quant Knowledge Base: Master Index

## Overview

This directory contains a structured, topic-organized knowledge base for quantitative finance, extracted from research documents, video transcriptions, and reusable code utilities.

## Usage

Each topic folder contains:
- **transcriptions/**: Searchable text from relevant video content
- **code_snippets/**: Production-ready Python functions and classes
- **README.md**: Topic-specific index and usage guide
