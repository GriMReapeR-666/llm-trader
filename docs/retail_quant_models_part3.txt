SECTION 9: RETAIL COMPOUNDING ENGINE (5 Pillars)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

9.1 PILLAR 1: Alpha Signal Layer
  Generate continuous Z-scores, not binary signals
  Incorporate regime filters (volatility, trend)
  Mean-reversion engines scale down during violent breaks

9.2 PILLAR 2: Dynamic Volatility Targeting
  Position_size = (Account * Risk_Target) / (k * ATR_20)
  Equalize dollar risk across all assets
  Prevents high-vol instruments from dominating

9.3 PILLAR 3: Fractional Kelly Sizing
  f* = (P_win * R - (1 - P_win)) / R
  Applied: 0.25 * f* (Quarter-Kelly)
  75% of max growth, 80% drawdown reduction

9.4 PILLAR 4: Portfolio De-Correlation
  Combine 4 uncorrelated sleeves (r <= 0.15):
    Sleeve A: Macro Trend (FRED-conditioned momentum)
    Sleeve B: COT Reversal (commodity/FX positioning)
    Sleeve C: Intraday MFT (volatility breakout/spread capture)
    Sleeve D: Stat-Arb (Kalman cointegration)
  Portfolio vol drops from 15% to 7.5%, variance drag halved

9.5 PILLAR 5: Trade Buffering (Robert Carver Rule)
  Execution buffer band: +/- 10%
  Only route orders when target deviates > 10% from current
  Eliminates fee drag from constant rebalancing

9.6 COMPOUNDING FORMULA
  CAGR ≈ mu - (1/2)*sigma^2
  Maximize: mu (mean return)
  Minimize: sigma^2 (volatility drag)
  Geometric growth = Arithmetic mean - Volatility drag

9.7 VARIANCE DRAG EXAMPLES
  Arithmetic 20%, Vol 20%: CAGR = 20% - (0.5 * 0.04) = 18%
  Arithmetic 20%, Vol 40%: CAGR = 20% - (0.5 * 0.16) = 12%
  Arithmetic 15%, Vol 10%: CAGR = 15% - (0.5 * 0.01) = 14.5%
  Lower vol beats higher arithmetic return

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

10.1 AUTHOR-C'S ROBUSTNESS CRITERIA
  1. Structural Economic Logic: Must exploit structural/regulatory cause
  2. Stationarity Verification: ADF / Johansen tests with zero lookahead
  3. Half-Life Time Exits: OU parameter decay stops
  4. Fractional Kelly Sizing: Never trade full Kelly (0.25x - 0.5x)
  5. Backtest Deflation: Haircut returns by 50% for live reality

  Occam's Razor: Models with fewer parameters outperform multi-indicator ML
  A 2-parameter system generalizes better than a 15-feature deep learning model

  The 50% Backtest Haircut Rule:
    Live Sharpe and CAGR will be at least 50% lower than backtested results
    Hurdle: Backtest Sharpe >= 2.0 (before costs), >= 1.0 (after friction)

  OU Time Stops Over Fixed Price Stops:
    Arbitrary fixed price stops harm mean-reverting strategies
    Cut positions right at maximum temporary dislocation before reversion
    Solution: If position fails to mean-revert within 2*lambda to 3*lambda bars, close

10.2 ROBERT CARVER'S SYSTEMATIC TRADING PRINCIPLES
  Position Buffering: +/- 10% threshold, only rebalance when exceeded
  Instrument Diversity: Trade 20+ instruments across asset classes
  Forecast Averaging: Combine multiple horizon forecasts
  Cost-Aware Optimization: Include transaction costs in portfolio optimization

10.3 AUTHOR-C'S ML FRAMEWORK
  Fractional Differentiation: (1-L)^d * x_t = epsilon_t, d from ADF
    Achieves stationarity while preserving long-term memory
    Find minimum d such that ADF p < 0.05

  Triple-Barrier Labeling:
    Upper: P_0 + k_1 * ATR (take-profit)
    Lower: P_0 - k_2 * ATR (stop-loss)
    Vertical: t_0 + tau_i (time expiration)
    Label = which barrier hit first

  Meta-Labeling:
    Primary model: direction (+1, -1, 0)
    Secondary model: P(correct | features)
    Size = f(P(correct))

  Combinatorial Purged Cross-Validation (CPCV):
    N distinct train/test paths (not single walk-forward)
    Purging: remove overlapping labels
    Embargoing: time delay after test set

  Deflated Sharpe Ratio:
    Accounts for number of trials, skewness, kurtosis
    If DSR < 0.05: strategy is likely false positive

  Hierarchical Risk Parity (HRP):
    Cluster assets by correlation
    Allocate risk within and across clusters
    No matrix inversion needed (robust to ill-conditioning)
