Secrets discipline. Passwords are referenced indirectly (password_env in config.ini, env names in accounts.json), account identity is stored as a hash (authenticated_account_fingerprint), the security audit scans for leaked credentials, and the data-quality gate explicitly rejects a market snapshot whose source identity "contains sensitive fields". A secret reaching the journal is treated as an integrity failure, not a cosmetic one.
