01 01. Executive Summary & System Identity

This repository is an institutional-grade, multi-agent autonomous trading system that trades MetaTrader 5 (MT5) instruments with a hybrid brain: a Large Language Model proposes trades from a fully deterministic, point-in-time market context, while a stack of non-LLM gates — validation rules, account-risk limits, a portfolio arbiter, margin safety, broker preflight — alone hold the authority to let an order reach the broker. Everything that happens is written to a single authoritative SQLite journal. Nothing in the research, machine-learning or self-improvement stack can trade by itself; it advises, and the gates dispose.

The one-sentence contract. The LLM proposes; DeterministicValidator + RiskManager + PortfolioRiskArbiter + margin/broker gates grant or deny permission; the journal (trading_state.db) is the source of truth; missing or stale data means HOLD.

01.3 The six non-negotiable doctrines

1. Stateless agents, stateful graph

Every agent stage reads a point-in-time slice of state, computes, writes back an immutable event, and ends. Continuity lives in the state tensor (SQLite + a keyed JSON↔SQLite store), never in process memory.

2. The LLM is a proposer, never an executor

A model may only emit a TradeProposal-shaped decision. The order API is called only downstream of the gates; there is no LLM path that reaches place_market_order directly.

3. Fail-closed

Missing ticks, stale marks, unknown spread, unmeasurable heat, absent broker spec, provider failure, unapproved execution policy → HOLD. "Unknown" is never treated as "safe".

4. The journal is the source of truth

Every proposal (approved and rejected), every lifecycle transition, fill and management action is persisted with its reason. Surfaces render the journal; they never fabricate values.

5. Research is advisory until promoted

Kelly / RL / Kronos / HMM output cannot mutate live risk parameters or size without passing the research-influence gate and the promotion funnel. The factory may demote its own work, but can never self-approve live authority.

6. Autonomy is bounded by levels

L0 shadow → L1 paper → L2 micro live (0.25 % risk per trade) → L3 full live (1 %). Escalation, demotion and every circuit trip are persisted and journalled.
