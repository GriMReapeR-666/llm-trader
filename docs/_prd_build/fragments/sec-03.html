03.3 Configuration resolution order

mt5_trader.py Config.from_sources() (~617) resolves in this precedence:

  1. AccountManager active account (accounts.json) â€” becomes the default credentials source.
  2. config.ini â€” [risk] risk_per_trade, max_drawdown; [limits] cooldown_seconds, max_trades_per_hour; [general] log_level; [trading] default_volume; [account] login / server / password_env.
  3. Environment variables override credentials: MT5_LOGIN, MT5_PASSWORD, MT5_SERVER win over both.
  4. Hard defaults: risk_per_trade=0.01, max_drawdown=0.10, default_volume=0.1, cooldown=300 s, max_trades_per_hour=5, log_level=INFO.

Environment variables relevant outside credentials include the provider fabric and budgets (OPENROUTER_*, TOKENROUTER_*, ROUTESME_*, CEREBRAS_*, NVIDIA_*), per-agent routing (TRADER_LLM_PROVIDER|MODEL|FALLBACK, ANALYST_*, RISK_*), fail-closed provider policy (LLM_TRADER_ALLOW_PROVIDER_FAILOVER=false by default â‡’ a provider failure becomes a deterministic HOLD), call timeouts (LLM_ROUTER_TIMEOUT=30, LLM_ROUTER_MAX_RATE_WAIT=15), the live opt-in (LLM_TRADER_ALLOW_LIVE=false), broker cost calibration (MT5_COMMISSION_PER_VOLUME, MT5_EXPECTED_SLIPPAGE_PRICE, MT5_EXPECTED_SWAP_MONEY â€” leaving these unset forces NO_TRADE in the net-R:R gate), the stage pipeline flag PIPELINE_V2, and the optional memory mirrors (REMOTE_MIRROR_*, LOCAL_MEMORY_*) which never grant execution authority.
