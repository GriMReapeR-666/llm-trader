21.3 Backups, security and alerts

  • Backups: operations/journal_backup.py performs AES-256-GCM encrypted backups, with restore and prune (--keep-backups, dry-run by default, explicit --apply, and a non-root destination guard). Legacy records are quarantined by operations/legacy_reconciliation.py.
  • Security: operations/security_audit.py scans for credentials and secrets; the result is disk-cached (.security_audit_cache.json) and prefetched asynchronously so paper boot is not blocked by a long scan. operations/security_scrub.py and operations/secrets_guard.py handle redaction; docs/SECURITY.md is the policy.
  • Alerts: operations/alert_outbox.py + alert_rules.py + alert_delivery.py implement enqueue → claim → ack → deliver in alerts_outbox.db (at-least-once; unacked alerts are recoverable via alerts-recover).
  • Readiness: operations/readiness_report.py aggregates every gate into a single operator verdict; operations/incident_drills.py rehearses the procedures in docs/INCIDENT_RUNBOOKS.md.
  • Metrics: operations/metrics_persistence.py, metrics_exporter.py and prometheus_exporter.py for observability.
