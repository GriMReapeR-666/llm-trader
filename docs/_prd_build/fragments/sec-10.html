10.2 Agent routing and failover policy

LLMRouter (~343) loads configuration from the environment (_load_config_from_env ~355), builds providers (_init_providers ~435) and agents (_init_agents ~457), and exposes register_agent(name, provider, model, fallback_providers) (~466), get_available_providers() (~476), get_available_models() (~479), configure(...) (~510), generate(agent, messages, model) (~539), generate_with_tools(...) (~633) and get_status() (~712).

Three logical agents are configured in .env.example, each with its own provider, model and fallback list: TRADER_LLM_*, ANALYST_LLM_*, RISK_LLM_*. The decisive switch is LLM_TRADER_ALLOW_PROVIDER_FAILOVER=false by default, documented in the file itself: "Default false: the selected provider is authoritative and its failure becomes a deterministic HOLD decision (fail-closed trade safety)." Set it to true to use the per-agent *_FALLBACK lists instead.
