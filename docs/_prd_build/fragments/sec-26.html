26.2 Running it

The repository standard (AGENTS.md) prefixes verbose commands with rtk for token-efficient output:

rtk python -m pytest -q
rtk python -m pytest tests/test_pipeline_v2.py tests/test_autonomous_gates.py -q
python mt5_trader.py llm-trade --symbol EURUSD --paper --loops 1   # one-shot paper smoke

The one-shot paper run is the highest-value end-to-end check: it must boot with positive equity and journal HOLD or REJECT rows rather than raising — a crash there means the boot/permission chain regressed.

26.4 What is not covered

  • Hanging / skipped suites — test_cli_profile_mounting.py and test_graph_engine_facade.py hang when run in batch (tracked as INFRA-004 in the repository's own planning notes); they are not part of the green baseline.
  • Broker reality — paper mode cannot prove fills against a live venue; broker-specific behaviour is covered by preflight/policy tests and by reconciliation, not by CI.
  • Provider behaviour — LLM providers are mocked in tests; the real contract is the deterministic_hold_fallback behaviour, which is tested.
  • Golden replay for Pipeline V2 stage split — pending the E3 work in §25.3.
