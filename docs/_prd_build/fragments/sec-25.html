25.2 The doctrine, restated as rules

  1. Unknown ≠ safe. Every gate has a defined value for "unmeasurable", and that value is a refusal.
  2. Fail closed at the boundary, continue below it. A data failure blocks analysis but not reconciliation, health checks or the kill switch.
  3. No silent repair. Execution plans are immutable; a ValueError becomes a HOLD, never a patched order.
  4. No silent skipping. A missed schedule shows up in its last_* state; a skipped candle shows up as a HOLD row.
  5. No silent authority. Nothing reaches the broker except through the documented gate chain.
