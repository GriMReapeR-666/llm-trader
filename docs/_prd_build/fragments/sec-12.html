12 12. Memory Architecture (L0–L3, Semantic, Local, Remote)

Memory answers "what did we learn, and may we still trust it?" It is a SQLite model with layers, as-of semantics, review gates and telemetry on every retrieval — not a prompt buffer that accumulates text.

The review gate is the point. L2 scenarios must be reviewed before they enter proposal context ("Require review before an L2 scenario can enter proposal context", ~869) and L3 memory is never returned to an agent until reviewed ("Human/operator review is mandatory for L3 policy/personality memory", ~979). Self-improvement can propose a policy change, but the system cannot adopt it by itself.

12.3 Retrieval: concurrent, bounded, instrumented

retrieve_for_proposal(tags, core_namespaces=…) (~1069) runs all seven read-only layers concurrently on worker threads, records per-layer telemetry through _record_retrieval(layer, tags, items, latency_ms, …) (~1044), and a failing layer degrades to an empty list plus an errors entry — "one broken layer can no longer stall or kill proposal assembly" (docstring ~1075–1080).

Every retrieval honours an as_of timestamp (_normalize_as_of ~302), so a replay or audit can reconstruct exactly what the system knew at that moment. Outcomes close the loop: link_retrievals_to_trade(retrieval_ids, ticket) (~1337) and resolve_retrieval_outcome(ticket, label) (~1346) let the system later measure whether the memories it used actually helped. Retention is explicit: prune_retrievals(keep_days=90, keep_linked=True) (~1145) keeps linked retrievals even when pruning.

12.4 Side memories

  • Semantic memory (intelligence/semantic_memory.py) — high-dimensional retrieval over scenario text, used when exact tag matching is too narrow.
  • Local agent memory (intelligence/local_llm_memory.py, local_agent_memory.py) — offline, local-only; controlled by LOCAL_MEMORY_ENABLED (default false), LOCAL_MEMORY_PATH, LOCAL_MEMORY_MAX_ACTIVE=5000, LOCAL_MEMORY_RETENTION_DAYS=90, LOCAL_MEMORY_COMPACT_KEEP=200.
  • Remote mirror (intelligence/remote_memory_mirror.py) — optional MySQL mirror (REMOTE_MIRROR_ENABLED=false, REMOTE_MIRROR_ON_WRITE, table prefix llm_trader_, 3 s connect timeout). The environment file states the rule: "Local SQLite … stays authoritative … Never grants execution_authority."
  • Case-study memory — intelligence/case_study_library.py, case_study_matcher.py, case_study_learner.py connect current setups to historical analogues.
